# Data and asset licensing

The MIT license applies to project-authored software and documentation only unless a file explicitly states otherwise.

It does not automatically apply to external source datasets, archival metadata, transcriptions, map/document images, museum images, or source-derived data with upstream conditions.

Every external source must have an entry in `research/sources.yml` and be reviewed in `docs/SOURCE_RIGHTS.md` before ingestion or publication.

When rights are unclear, default to linking/citing the source rather than redistributing the payload. This is project governance, not legal advice.
