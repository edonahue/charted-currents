# Working conventions summary

This repository favors small, polished, evidence-backed vertical slices; canonical sources of truth; explicit public/private boundaries; verification that matches the claim being made; documentation synchronized with reality; measured optimization; and concise auditable handoffs.

Canonical detail lives in:

- `docs/MAINTAINER_EXPECTATIONS.md`
- `docs/PUBLIC_PRIVATE_BOUNDARY.md`
- `docs/IMPLEMENTATION_CONTRACT.md`
- `docs/AGENT_EXECUTION_PLAYBOOK.md`

Do not duplicate those policies here or in additional tool-specific instruction files.
