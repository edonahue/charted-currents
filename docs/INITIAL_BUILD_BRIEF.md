# Initial build brief for Gemini 3.7 Flash

## Mission

Create the first visual/technical vertical slice without expanding the historical corpus beyond verified sample data.

## Sequence

1. **Foundation** — Astro + TypeScript, strict checks, design tokens, accessible shell, static deployment assumptions.
2. **Map** — MapLibre, Greater Caribbean camera, original light historical-atlas style, verified sample ports/routes, inspector-first selection.
3. **Timeline** — compact persistent timeline, context markers, coverage-gap data contract; no simulation engine yet.
4. **Inspectors** — ship, port, voyage, person, context/event.
5. **Provenance** — source drawer, evidence badges, Research View surface, source identifiers and links.
6. **Historical asset** — one rights-cleared period map/reference image or raster layer with full attribution; inspectable rather than decorative.
7. **Context** — one separate contextual event with no implied causality.
8. **QA** — responsive, keyboard, contrast, reduced motion, map attribution, source-link and fixture validation, no unsourced copy.

## Acceptance

Reject a technically correct build if it looks like a generic MapLibre demo, reads like a dashboard, buries provenance, makes all routes look equally certain, makes the map secondary to cards, treats historical imagery as texture, or slips into parody pirate theming.

## Do not do yet

No full Crespo ingestion unless explicitly tasked, DuckDB-Wasm, PMTiles, backend/API, dynamic AI feature, extensive dashboard charts, global Atlantic map, historical route simulation, or unsupervised extraction into published data.
