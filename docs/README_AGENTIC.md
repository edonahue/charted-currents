# Agentic repository guide

Charted Currents is designed to be worked on by coding agents, but the repository—not the model—owns durable product, historical, rights, and architecture decisions.

The fast path for an agent is:

1. read `GEMINI.md`;
2. use `docs/AGENT_CONTEXT_INDEX.md` to load only relevant context;
3. follow `docs/MAINTAINER_EXPECTATIONS.md` for scope/review/verification conventions;
4. follow the current session in `docs/FIRST_SESSIONS.md`;
5. use `docs/IMPLEMENTATION_CONTRACT.md` for locked engineering defaults;
6. use `docs/PUBLIC_PRIVATE_BOUNDARY.md` before committing data, config, screenshots, logs, environment details, benchmarks, or source material;
7. close with observed evidence and explicit unresolved items.

This document is intentionally short. Detailed policy lives in the linked canonical files rather than being duplicated here.
