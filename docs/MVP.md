# v0.1 vertical slice

## Goal

Prove that Charted Currents can be **beautiful, historically credible, and genuinely explorable** with a small corpus of real records.

## Required experience

### Map
- MapLibre-based Greater Caribbean map.
- Modern cartography influenced by period charts.
- Warm/light default theme.
- Port Royal connections visible immediately.
- Restrained camera/route animation.
- No fake exact ship positions.

### Inspector
Clicking an entity opens an inspector while preserving the map. Initial types: ship, port, voyage, person, event/context.

### Corpus target
Approximately:
- 10–20 real source-backed vessels;
- 6–15 ports;
- enough voyage legs for repeated connections;
- several multi-record ship histories;
- one or more prominent pirate/privateer profiles;
- one major contextual event;
- one hurricane context if source coverage supports it;
- one properly licensed period map/reference layer;
- representative primary-source/document links.

### Timeline
Persistent compact timeline that can filter evidence, show contextual events, and visualize source-coverage gaps. Architect toward richer time scrubbing later.

### Provenance
Evidence state on every relationship, source drawer/card, direct source links where possible, optional Research View.

### Routes
A route between known endpoints is **schematic** unless actual track evidence exists. Historically reconstructed routes are a desired later research feature and must remain visibly distinguished from observed tracks.

## Analytics in v0.1

Only defensible measures: port connectivity, route counts, ship mobility/range, traffic composition, and source coverage. Predation enrichment waits for a defensible denominator corpus.

## Not v0.1

No production API/backend, full Caribbean corpus, accounts/social features, corpus chatbot, exact simulated ship positions, broad claims of completeness, generic gamification, or unvalidated AI-extracted facts.
