# Project brief

## Working identity

**Charted Currents — The Greater Caribbean · 1650–1730**

Working subtitle: *Ships, trade, weather, and predation in the age of piracy.*

Charted Currents is an **exploratory data product with serious historical standards**. It is not primarily a pirate encyclopedia, generic GIS dashboard, comprehensive academic database, game, or AI showcase.

## Desired feeling

Priority:
1. “I want to click around this map.”
2. “This feels like entering the maritime Caribbean of this period.”
3. “There is a remarkable amount of historical detail here.”
4. “I just learned something surprising.”

## Core thesis

Separate archives record fragments of the same historical world. Charted Currents should connect those fragments carefully enough that users can see relationships difficult to discover in any one archive, while preserving the uncertainty and provenance of every connection.

## Audiences

1. Pirate and maritime-history enthusiasts.
2. The maker as a genuine exploratory tool.
3. Data-product / visualization practitioners.
4. Professional portfolio viewers.
5. Students and teachers.

## Public posture

- polished public experiment from commit one;
- academically serious source/provenance posture;
- maker identity present but restrained;
- AI is tooling, not the public thesis;
- initial website target: `erichdonahue.com/labs/charted-currents/`;
- standalone domain later only if warranted.

## Sid Meier's Pirates! influence

The 2004/2005-era game is a meaningful interaction ancestor because its map is the world: cities, ships, wind, time, and events coexist on a recognizable Caribbean surface. Charted Currents should borrow that exploratory mental model without copying Firaxis assets, UI composition, trade dress, text, or audio.

## Pirate Arcade relationship

Pirate Arcade is a minor shadow/sister project. It may link prominently to Charted Currents. A reciprocal link should remain subtle. Charted Currents can inherit family-level cues such as restrained nautical vocabulary and deep-ocean/brass/sea/paper color relationships, but should be substantially more refined and historically grounded.
